# SMART FARM 3D — Android starter

This is a beginner starter Flutter project. It currently includes manual land dimensions, square-feet/acres calculations, and basic soil/season selections.

## Build an APK with GitHub Actions
1. Create a GitHub repository.
2. Upload the contents of this project to the repository (including the `.github` folder).
3. Open the repository's **Actions** tab and enable workflows if GitHub asks.
4. The workflow named **Build Android APK** runs on push.
5. When it finishes successfully, open the workflow run, scroll to **Artifacts**, and download `smart-farm-3d-apk`.

## Important limitations
No real 3D terrain, AI photo/video analysis, GPS, live weather, cloud database, scientific soil diagnosis, or validated district-level crop recommendations are included. The APK is not production-ready.
